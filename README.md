# Polyglot Cards

A free flashcard app for learning English, German and Spanish with spaced repetition, pronunciation and a sentence-mining reader.

- Spaced-repetition review (Again / Hard / Good / Easy)
- Text-to-speech in three languages
- Reader: paste a text, click words, add them to your deck with their sentence
- Search, edit, stats, and backup/import
- Your cards are stored only in your own browser

Built with plain HTML, JavaScript and Tailwind CSS.
